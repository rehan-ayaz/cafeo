## Decisions and limits

Reservation buttons use the existing `/contact-us` route. Dedicated Reservations and Offers routes are absent from the source router.

Canonical and social URLs default to `https://cafeo.com`, as declared by the existing project. Set `VITE_CAFEO_SITE_ORIGIN` before building for a different production domain.

The original nine legacy blog routes are retained. The new listing publishes the 14 requested Cafeo articles.

The existing footer form is reused. End-to-end newsletter email delivery was not tested. No separate newsletter section was added to the listing.

Verification used local Chrome and the local production server. Public hosting deployment was outside the requested local website update.

## Delivery

`cafeo-complete-blog-system.zip` contains the React source, all public assets, all 84 new optimized blog photos, content data, blog components, SEO and build scripts, package files and both reports.

Dependencies, prior backups, build output, browser profiles, exploratory image sheets and temporary QA files are excluded. Reinstall with `npm ci`, then use `npm run build` and `npm start`. The original project backup is retained separately.
